# DeltaUnlimited 模块说明

> 三角洲行动 · 烽火地带"跑刀"流程自动化辅助（**只做拾取与撤离流程自动化，不含战斗/击杀辅助**）。
> 本文档基于当前源码（v0.3.0，net10.0 / C#）整理，按"入口 → 命令层 → 核心服务层 → 数据层"分层说明各模块职责与关键 API。

## 1. 总体架构

```
Program.cs（入口：初始化 + 命令路由；无参数/gui → 图形控制面板）
   │
   ├── Cli/Commands/*.cs      命令层（12 个命令，每个对应一个 CLI 动词）
   ├── Cli/CommandUtil.cs     协作式急停（StopRequested）/ 暂停点闸门（PauseGate）/ 语义键解析
   ├── Cli/InputProbe.cs      动作探针（动作前后帧差验证，hold/turn 共用）
   ├── Gui/*.cs               图形控制面板（主窗口 + 托盘 + 控制台分流日志）
   │
   ├── Capture/CaptureService.cs   截屏服务（窗口定位 + GDI 截图 + 窗口坐标换算）
   ├── Vision/*.cs                  视觉层（模板匹配 / 界面识别 / 帧差 / 帧归一化 / 标注）
   ├── Input/InputService.cs        输入层（SendInput 键鼠模拟，拟人化）
   ├── Overlay/*.cs                 可观测层（统一日志 + 游戏画面悬浮状态面板）
   │
   └── Data/*.cs                    数据层（JSON 模型 + 加载器）
            │
            ├── data/*.json         运行时数据（elements/screens/game_ops/runtime/...）
            ├── workflows/*.json    链路定义（enter_match 等）
            └── assets/templates/   识别模板小图
```

- 入口：`Program.cs`（`DeltaUnlimited/Program.cs`），只负责根目录定位、日志初始化、拟人化参数注入、命令分发。
- 依赖包：`OpenCvSharp4`（视觉）、`Vanara.PInvoke.Gdi32/User32`（Win32 封装）。目标框架 `net10.0`。
- 设计基准：所有元素坐标/模板/识别统一在 **1920×1080 设计分辨率** 上进行，运行时按窗口实际尺寸缩放。

## 2. 命令层（DeltaUnlimited/Cli/）

| 命令 | 文件 | 功能 |
|---|---|---|
| `smoke` | `Commands/SmokeCommand.cs` | Phase 0 数据层冒烟：加载全部 JSON 并打印统计 |
| `annotate` | `Commands/AnnotateCommand.cs` | 静态识别冒烟：对截图画标记（coord 画十字 / template 画框）输出到 `screenshots/annotated/` |
| `capture` | `Commands/CaptureCommand.cs` | 截屏冒烟：截桌面或指定窗口客户区 → `screenshots/captured/` |
| `click` | `Commands/ClickCommand.cs` | 真实点击：点前/点后自动截图，3 秒倒计时可取消，坐标按设计分辨率缩放 |
| `hold` | `Commands/HoldCommand.cs` | 长按测试：`hold <键名> <毫秒>`，帧差验证（经 InputProbe） |
| `turn` | `Commands/TurnCommand.cs` | 视角转动测试：`turn <dx> [dy]`，帧差验证（用于标定 px_per_90deg） |
| `drill` | `Commands/DrillCommand.cs` | 靶场自主行进循环：冲刺前进 + 右转 90° 的四边回路，每步帧差确认，失败重试一次后中止 |
| `patrol` | `Commands/PatrolCommand.cs` | 反应式巡逻 v2：持续冲刺前进，双守卫（贴墙停 + 横移低效）自动右转 |
| `chain` | `Commands/ChainCommand.cs` | 顺序链路 runner：按 JSON 步骤执行，支持分支/跳转/点击后验证（详见 §3） |
| `crop` | `Commands/CropCommand.cs` | 从截图裁模板小图，支持缩放换算到设计分辨率 |
| `ocr` | `Commands/OcrProbeCommand.cs` | 对一张截图做 OCR 诊断（词表 + 关键词严格/候选匹配验证） |
| `tplprobe` | `Commands/TplProbeCommand.cs` | 对一张截图做模板匹配诊断（置信度/命中位置） |
| `mousetest` | `Commands/MouseTestCommand.cs` | 拟人鼠标轨迹验收：从当前光标到指定坐标画弧线（不点击），可多次运行观察随机性 |
| `overlay` | `Commands/OverlayCommand.cs` | 悬浮状态面板：把 `logs/status_*.log` 尾部渲染到游戏画面上（常驻进程） |
| `windows` | `Commands/WindowsCommand.cs` | 列出当前可见顶层窗口（调试窗口定位用） |

**命令层公共工具：**

- `Cli/CommandUtil.cs`
  - `InstallEmergencyStop()`：注册 Ctrl+C 急停——置 `StopRequested` 标志 + 释放所有按键（不再 Environment.Exit：链路/巡逻/训练循环在步骤边界与轮询点检查标志，优雅收尾后进程自然退出，退出码保持 130）。
  - `AbortIfStopped()`：急停检查点，已请求则抛 `ChainStoppedException`（命令层捕获后收尾）。
  - `WaitForResume(message)`：人工确认点——CLI 轮询回车（可被急停打断）；GUI 注入 `PauseHandler=PauseGate.Wait` 后由主窗口"继续/中止"按钮放行。
  - `ResolveKey(data, semantic)`：语义键名 → 实际按键（查 `game_ops.json` 的 `按键映射`，查不到按原样返回）。
- `Cli/InputProbe.cs`
  - `Run(repoRoot, winKeyword, describe, action)`：动作前/后各取一帧（内存），用 `FrameDiff` 计算帧差并给判定结论（≥3 明显变化 / ≥0.8 轻微 / 无变化），显著变化时保存证据帧。`hold`/`turn` 共用。
- `Cli/Usage.cs`：打印 CLI 用法说明。

## 3. ChainCommand 链路引擎（核心决策雏形）

`chain <workflow文件> [--auto]` 按 `workflows/*.json` 中 `steps` 数组顺序执行，支持以下 `op`：

| op | 说明 |
|---|---|
| `key` | 抢焦点后按键（`InputService.PressKey`） |
| `click_element` | 点击元素表元素：置顶 → 抢焦点 → 设计分辨率坐标缩放 → 拟人化点击；支持 `expect_screen`/`timeout_ms`/`retries`：点击后轮询验证目标界面，失败自动重试并留证据帧 |
| `if_ocr` | 关键词条件分支：当前帧 OCR 严格命中任一关键词则跳转 `jump_to`（如入局提醒弹窗内的"未转移"行检查），OCR 不可用判未命中（fail-open） |
| `pick_operator` | 干员选择：运行时 OCR 定位类型标签→相对偏移点头像（不可见则滚轮翻动重识别；未配置 `operator_presets.map_operators` 则跳过保持当前）。标签带按 ≤760px 分段 OCR（1.5x 放大生效，艺术字标签识别稳定），按锚点距离优先识别目标段、命中即停；未命中时打印词表诊断 |
| `switch_screen` | 界面分流：一次截图+识别后按 `branches` 表跳转（未匹配走 `default` 兜底；default 连续触发超 `max_loops` 熔断人工确认）——识别循环的 12 个 if_screen 由此合并为 1 步。检测到带 `dismiss` 键的弹层界面（如 space_continue 空格继续）→ 自动按键关闭并重跑本步骤 |
| `wait` | 空操作（统一在步骤末尾按 `wait_ms` 等待） |
| `wait_screen` | 轮询等待界面出现/消失（`absent: true` = 等待消失），超时可选 `jump_to` 跳转。等待期间检测到带 `dismiss` 键的弹层 → 自动按键关闭后继续轮询（不消耗额外超时） |
| `detect` | 识别当前界面并打印（含未配置标记的界面诊断提示） |
| `if_screen` | 界面判断分支：当前界面 == 期望则 `jump_to` |
| `if_template` | 模板匹配分支：命中则 `jump_to` |
| `jump` | 无条件跳转到指定步骤 id |
| `pause` | 人工确认点（半自动模式回车继续，`--auto` 跳过） |
| `mark_unknown` | 未知界面标记：截图 + 界面候选 + 全帧 OCR 词表存入 `screenshots/unknown/`，再按 `message` 提示人工处理（回车继续；`--auto` 下不等待） |

半自动默认带人工确认点；`--auto` 全自动。Ctrl+C 随时急停。

## 4. 截屏服务（DeltaUnlimited/Capture/CaptureService.cs）

窗口定位 + GDI 截屏（开发期方案，适用窗口化游戏；后期换 Windows.Graphics.Capture 时保持公开方法不变）。

| 方法 | 功能 |
|---|---|
| `EnsureDpiAwareness()` | 设置 Per-Monitor V2 DPI 感知，避免缩放下坐标错位 |
| `ListTopLevelWindows()` | 枚举所有可见顶层窗口（标题非空） |
| `FindWindowByTitle(keyword)` | 按标题关键字找窗口，排除自身控制台与命令行走廊窗口 |
| `GetClientScreenRect(hwnd)` | 客户区在屏幕上的矩形（最小化返回 null） |
| `GetWindowScreenRect(hwnd)` | 含边框的窗口矩形（调试用） |
| `RaiseWindow/UnraiseWindow(hwnd)` | 窗口置顶 / 还原层级（截图、点击前用） |
| `CaptureDesktop(pngPath)` | 截整个桌面（截屏冒烟用） |
| `CaptureWindowClient(titleKeyword, pngPath)` | 置顶 → 截客户区 → 还原，存 PNG（返回平均色，`LooksBlack` 检测疑似黑屏） |
| `CaptureWindowMat(titleKeyword, raiseAndWait)` | 截客户区返回内存 BGRA Mat（不落盘，供帧差/识别；`raiseAndWait=false` 连续采样提速） |

实现要点：`CreateDIBSection` + `BitBlt(SRCCOPY|CAPTUREBLT)`，负高度 DIB 保证行序与 Mat 一致；截图源用桌面 DC + 客户区屏幕坐标（窗口 DC 部分环境会全黑）。

## 5. 视觉层（DeltaUnlimited/Vision/）

| 文件 | 职责 |
|---|---|
| `ScreenDetector.cs` | **界面识别器**：用 `screens.json` 的标记判断当前帧属于哪个界面。`Scan()` 返回按置信度降序的全部候选（含未完全命中，用于校准阈值）；`Detect()` 返回最佳命中界面（无命中返回 null）；`UnconfiguredScreens()` 列出未配标记的界面（诊断防静默失败）。标记全部命中才判定为该界面，分数取最差命中置信度 |
| `TemplateMatcher.cs` | **内存模板匹配**（不落盘）：`Match(frame, templatePath, threshold)` 用 CCoeffNormed 找最佳位置。模板按路径缓存在 `ConcurrentDictionary`，避免循环中反复读盘（#4）。自动处理 BGRA(4ch)→BGR(3ch) 转换 |
| `FrameDiff.cs` | **帧差检测**：两帧平均绝对像素差（0–255），用于验证移动/转向是否生效、贴墙/卡住判定。尺寸不一致自动缩放 |
| `FrameTools.cs` | **帧归一化**：运行时帧统一缩放到设计分辨率（1920×1080），模板/识别在基准上执行 |
| `MatchResult.cs` | 匹配结果记录 `(Found, Confidence, CenterX, CenterY, W, H)`，TemplateMatcher / ImageAnnotator 共用 |
| `ImageAnnotator.cs` | **静态标注工具**：对截图画标记输出新 PNG。"看得见的识别冒烟"。`AnnotatePoint`（coord 策略画十字/圆）、`AnnotateTemplate`（template 策略画绿框 + 中心十字，返回最佳位置供回填 coord） |

## 6. 输入层（DeltaUnlimited/Input/InputService.cs）

键鼠输出（SendInput 模拟真实输入），拟人化参数全部来自 `runtime.json → humanizer`，调参不改代码。⚠️ 铁律：所有拟人化参数必须保持随机范围（min/max 或概率），禁止收敛为固定值——轨迹/节奏随机性是防机械感的核心（见 `MousePathPlanner`）。

**窗口坐标系**（2026-09 修）：截图按窗口客户区，点击按全屏曾导致窗口化/DPI 缩放下点错位。现在统一由 `CaptureService.MapDesignToScreen` 做「设计坐标 ×(客户区/设计比) + 客户区屏幕原点 → 屏幕绝对坐标」，`ElementClicker` 与 `OperatorPicker` 点击前都必须换算（纯函数，有单测）。

| 方法 | 功能 |
|---|---|
| `Configure(config)` | 注入拟人化参数（启动时调用），并设置 Per-Monitor V2 DPI 感知 |
| `ClickAt(x, y)` | 拟人弧线移动 + **点击安全网**：读回校验落点，偏差 > `humanizer.mouse.verify_tolerance_px`（默认 6px）→ 直接绝对钉正一次 → 再校验仍偏 → **放弃点击返回 false**（fail-open，绝不盲点）；点击只发生在校验通过的位置 |
| `MoveHumanized(x, y)` | 拟人鼠标移动（同 ClickAt 的移动部分）：路径由 `MousePathPlanner` 规划，参数来自 `runtime.json → humanizer.mouse` |
| `MoveAbsoluteTo(x, y)` | 绝对定位（SendInput 归一化 0–65535，不受鼠标加速影响） |
| `MoveTo(x, y)` / `MoveRelative(dx, dy)` | 平滑移动：分段正弦缓动 + 随机抖动 + 每步随机间隔，重归一化保证总和精确 |
| `PressKey(key)` | 短按（支持 `"ctrl+left"` 组合串与鼠标键 token left/right/middle） |
| `HoldKey(key, ms)` / `HoldKeys(keys, ms)` | 组合长按（时长抖动），异常兜底全释放 |
| `PressKeys(keys)` | 持续按住不自动松开（持续移动用，必须配 `ReleaseAllHeldKeys`） |
| `ReleaseAllHeldKeys()` | 释放所有仍按住的键/鼠标键（急停/异常兜底，可重复调用） |
| `EnsureForeground(hwnd)` | 确保窗口持有键盘焦点（FPS 必需）：模拟 Alt 让本进程获得前台权限后 `SetForegroundWindow` |
| `IsForeground(hwnd)` | 窗口是否当前前台 |
| `MapKeyName(key)` | 按键名/字符 → 虚拟键码（单字符 + 常用名，测试覆盖） |
| `SplitCombo(key)` | 组合串按 `+` 拆分 |

实现细节：修饰键归一化为左侧键码（部分游戏引擎不认通用 VK_SHIFT/CONTROL/MENU）；键盘事件自动补扫描码（`MapVirtualKey`）；INPUT 结构体 40 字节 x64 显式布局。

## 10. 链路定义（workflows/）

| 文件 | 内容 |
|---|---|
| `enter_match.json` | 进场链路 v7（switch_screen 一次识别查表分流，112步→~64步）：主循环=12 已知界面+default 兜底一次分流，分支动作统一汇聚回主循环；广场(常态)→点配装→裸装鉴别(未装配≥4)→制式套装→均衡→确认配装→出发 / 广场(首次)→行前备战→轮询等待地图池；部署面板→开始行动（裸装可跳过配装界面直进入局提醒）；入局提醒→未转移行检查→仍要继续；匹配→自动选干员（未配置保持当前；15s 倒计时自动开局）→结束；未知→Tab 兜底（熔断 max_loops=3）；失败软跳转+mark_unknown 留证+人工确认 |

## 14. 图形控制面板（DeltaUnlimited/Gui/）

| 文件 | 职责 |
|---|---|
| `GuiApp.cs` | GUI 入口：控制台分流 → 拟人化参数/OCR 初始化 → 专用 STA 线程跑 WinForms 消息循环（控制台主线程是 MTA，不能直接跑 WinForms） |
| `MainForm.cs` | 主窗口：工作流/模式选择、**开始/急停**（后台 Task 执行链路 + 协作式急停）、**暂停面板**（半自动人工确认点：非模态"继续/中止"，急停按钮始终可用）、状态栏、日志窗（封顶 3000 行+自动滚屏+清空）、系统托盘（关闭/最小化收进托盘、双击恢复、右键菜单：显示/开始/急停/退出、链路结束气泡通知） |
| `ConsoleRelay.cs` | 控制台分流器：接管 `Console.Out/Error`（Tee）——原输出照写 + 每行推给订阅者；订阅前输出进 200 行环形缓冲，首个订阅者接入时补发（启动日志不漏） |
| `WorkflowCatalog.cs` | 工作流扫描：`workflows/*.json` 文件名列表（纯函数，有单测） |
| `AppIconFactory.cs` | 运行时绘制托盘/窗口图标（32×32 圆底+DU 字样），无外部素材依赖 |

设计要点：GUI 与 CLI 共用全部核心（截屏/识别/输入/数据/链路/急停/暂停闸门），日志窗是纯展示（订阅 + 100ms 批量刷新，不阻塞链路线程）；链路在后台 Task 执行，急停走 `CommandUtil.StopRequested` 协作式标志（GUI 按钮/Ctrl+C/暂停面板"中止"三路同源），任何路径都保证释放全部按键；WinForms 的 `System.Drawing`/`System.Windows.Forms` 全局 using 已在 csproj 用 `Using Remove` 移除（避免与 OpenCvSharp 的 `Size`/`Point` 二义性），GUI 文件自行显式 using。

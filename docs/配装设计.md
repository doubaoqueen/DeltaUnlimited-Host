# 自动配装设计（制式套装方案 v1）

状态：**设计定稿，部分落地**。界面/元素表已入库；链路接入只差"均衡卡消耗按钮"坐标标定（见 §标注清单）。

## 方案选型

用游戏内置「制式套装」预设实现自动配装，替代全槽位逐一标注方案：

- 流程：配装界面点「制式套装」卡片 → 装备预设界面选卡 → 自动回配装界面 → 点「确认配装」。
- 成本：**确认配装时才真正消耗制式装备券**（新兵券 ≈ 5 万哈夫币/局）；确认前随时可点 X 取消、不扣券 —— 天然安全，适合迭代测试。
- 预算上限字段 `budget_cap` 已在 `data/loadout_preset.json` 预留（schema 1，presets 空）；将来想换方案只改数据不动链路。

## 真机流程（2026-09-22 口述标定，见 docs/配装场景问题清单.md）

1. **配装界面**点「制式套装」卡片（(1660,880)-(1730,898)，美术字，模板已裁 `standard_set_card.png`）→ 进入**装备预设界面**。
2. **装备预设界面**：
   - 顶部 5 个方向标签：新兵/标准/精锐/特种/定制，各带 [卡片数量]；**悬停=方块底部变绿，点击选中=整体边框变绿**；点击切换推荐列表。零号大坝-常规模式下默认即「新兵」→ **MVP 不点标签**。
   - 中部 3 张预设卡：**均衡/生存/火力**（卡名肉眼可读，OCR 待验证）；每卡底部有"消耗券"按钮，**点击直接回配装界面，无二次确认**。
   - 右上额度标识：4 张券图（新兵/标准/精锐/特种制式装备券；定制券已取消）。
   - **失败分支**：点卡后若不符合地图/等级/模式规则，**顶部提示约 1.5 秒**："xx制式装备券 无法进入零号大坝-常规"（券名黄色、后半白），画面停留在预设界面。
3. **回到配装界面**：底部出现预设弹框（X = 取消当前预设装备）。**弹框不自动消失、不挡「确认配装」按钮** → 不点 X，直接点确认配装。
4. 点「确认配装」→ 真正扣券 →（入局提醒）→ 出发。

## 识别与链路设计

- **新界面 `preset_select`**（screens.json 已入库）：OCR 标记 `均衡/生存/火力` 任一命中（全帧；⚠️ 待真机截图后做串台测试，必要时加区域限制）。动作=点均衡卡消耗按钮。
- **元素**：
  - `standard_set_card`（elements.json 已入库）：template 主定位 + 坐标兜底 (1695,889)。
  - `preset_balanced_button`（均衡卡消耗按钮）：**待标定** —— 唯一缺口。
- **成败判断（难点 2 对策）**：不追 1.5s 的瞬态提示，用**状态迁移**判断——点消耗按钮后 2.5s 内识别"回到配装界面"=成功；超时仍在预设界面=失败 → 走失败分支。若能顺手 OCR 到"无法进入"则日志写明原因，抓不到也不影响判断。
- **链路插入点**（enter_match.json）：
  ```
  loadout 分支 → 点 standard_set_card (expect preset_select)
              → 点 preset_balanced_button (expect loadout, timeout 2.5s, 失败跳 preset_fail)
              → confirm_loadout（既有）
  preset_fail → detect → loadout?→confirm_loadout / preset_select?→mark_unknown(提示:可能券不可用)
              → detect_start
  ```
- **额度图标 4 张券**：识别用途（可选优化），暂不实现；优先级低于链路打通。

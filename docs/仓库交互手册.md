## 品质识别：格子背景色

物品装在格子里，**格子的背景色代表品质**：白 / 绿 / 蓝 / 紫 / 金 / 红（档位顺序按此；红=特殊/最高，待真机标定）。
识别管线：**OCR 名称为主 → 格子背景色判品质 → 模板/ORB 兜底**（不搞每物品一张模板的大库）。

## 容量规则（固定事实）

- 裸装干员：**5 个单格口袋 + 安全箱**（新手安全箱 = 2 格）；
- 固定装备槽：**长枪×2、手枪×1、头盔×1、防弹衣×1、胸挂×1、背包×1**；
- 胸挂/背包按类型扩展容量，且有**物品类型限制**（不是什么都装得下）；
- **默认不占用安全箱与门禁卡包**（门禁卡包 = 独立容器）——战前无特殊要求就空着，留给局内战利品。

## 配装模式（GUI 预留）

- **制式套装**：直接**卸掉原有身上套装**，换上预设套装（确认配装时才扣券）；
- **仓库优先**：完全不用制式套装，从仓库按规则自选携带，缺则跳过不补；受"最高携带品质档位"限制；
- 战前携带物品种类 ≈ **十几二十种**（最基础模式，用户往多估）——知识库从小做起；
- 局内物品很多，但**需要拾取的有限**（拾取清单另建，物品库字段 `pick` 已预留）。

## 数据槽

- `data/item_catalog.json`：条目字段 name（OCR 关键词）/ ocr_keywords（变体）/ type / tier（白绿蓝紫金红）/ grid_w·grid_h（占格）/ value（哈夫币）/ pick（是否值得拾取）/ note；**增量录入**。
- `data/loadout_preset.json → policy`：`source` = preset | warehouse；`max_tier` = 白1/绿2/蓝3/紫4/金5/红6（0=不限）。

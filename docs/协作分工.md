## 1. 协作铁律（所有助手必须遵守）

1. **文件独占**：每条工作线只改自己白名单内的文件；白名单外的文件一个字节都不动。
2. **不碰 git**：助手不 commit、不 push、不删文件、不移动文件——产出 = 改动文件 + 说明，交给主力统一 review 后提交。
3. **测试是门禁**：任何改动必须 `dotnet test tests\DU.Tests` 全绿（当前基线 99 用例）才算交付。
4. **数据与配置**：`data/*.json` 里用户标定的数值（坐标/阈值/预设）未经用户同意不得改值；只允许新增字段或修复格式错误。
5. **红线**（`docs/项目大纲.md`）：不写任何战斗/击杀/瞄准辅助；不读内存；所有自动化必须可被人即时打断。
6. **遇到方案级分歧** → 写"需主力决策"报告，**不得自行发明方案**。

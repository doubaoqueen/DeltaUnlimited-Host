# 02 时间线

> [!info] 一句话
> 这个项目从 2026 年 9 月初的一堆空文件，走到 10 月底"进场全自动 + 跑刀撤离在收尾"，一共就两个月。这篇按时间把大事串一遍——**每一行都能点进对应的笔记看细节**。

> [!tip] 日期怎么算的
> 优先用 Git 提交日期和文档头部写明的日期；只知道大概时段的，写成「9 月中」「10 月上」这类模糊说法，**不编精确日期**。

> [!warning] 一处日期对不上（❓待确认）
> `runtime.json` 的注释说轮询间隔是「2026-09-30 由 600 降到 300、等待循环已加变更门」，但 `ChangeGate.cs` 这个文件在 Git 里首次出现是 **2026-10-10**（提交 `8fdebcc`）。本文按 Git 日期写成 10-10，具体是哪天以当时的真机记录为准。

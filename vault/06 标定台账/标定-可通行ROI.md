# 标定：可通行性 ROI（模型看哪块地面）

> [!info] 一句话
> 可通行性模型不看全屏，只看**屏幕中下方一块 648×324 的 2:1 矩形**（`[592, 656, 648, 324]`，1920×1080 设计分辨率），缩成 **112×224** 喂给网络。
> 这块框就是"模型的视野"——框歪了，模型看到的是天、是手、是墙，判断必然错。

## 数值

| 参数 | 值 | 含义 |
|---|---|---|
| `roi` | **[592, 656, 648, 324]** | 裁剪矩形：x=592, y=656, 宽=648, 高=324（设计分辨率坐标） |
| 宽高比 | **2:1**（648/324） | 标准比例，`roitune` 锁 2:1 联动 |
| `input_size` | **[112, 224]** | 网络输入（高 112 × 宽 224，与 ROI 同比，无拉伸） |
| ROI 中心 | (916, 818) | 画面中下方偏下——准星落地区域 |
| `min_confidence` | 0.7 | 低于此值的判断当"不确定" |
| `filter` | window=5 / k=3 / motion_diff_threshold=12.0 | 时域滤波：5 帧里 3 帧一致才预警；画面在动（帧差>12）时压制预警 |
| `runtime_threads` | 4 | 实测 4 最优（默认全核反而慢且 p99 抖动大） |

## 怎么标定的

用 **`roitune`**（ROI 调参器，实时/静态两种）：

| 操作 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动绿框 |
| `Q` / `E` | 宽 ± |
| `Z` / `C` | 高 ± |
| `F` | **锁 2:1**（宽高联动，同时按比例联动 `input_size`，保持宽 224） |
| `回车` | 保存写回 `data/ai_vision.json` |
| `R` / `Esc` | 还原 / 退出 |

标定过程（用户 2026-09-28 定稿）：

1. 进游戏、站在正常对局画面，打开实时预览；
2. 拖动绿框到"站在这里，看这块就能判断能不能往前走"的区域——**中下方地面**，避开天空、手指、HUD；
3. 锁 2:1（自由比例时 `roitune` **只改框、不改 input_size** → 画面被拉伸，代码里专门有这条风险提示，见下）；
4. 回车写回。`input_size` 自动联动成 `[112, 224]`。

**一次历史变更（说明为什么值得记）**：

| 时间 | ROI | 比例 | input_size | 说明 |
|---|---|---|---|---|
| 2026-09-28（`3a2f3df`） | `[416, 592, 1088, 388]` | 2.80 : 1 | `[80, 224]`（同比例） | 第一版标定（"等比输入"，但比例不是 2:1） |
| 2026-09-28（`8f122cb`） | **`[592, 656, 648, 324]`** | **2 : 1** | **`[112, 224]`** | 用户定稿，标准 2:1（"input_size 回归 112×224"） |

> [!warning] ROI 与 input_size 必须同比
> 自由比例时 `roitune` 只改框、不改输入尺寸，**画面会被拉伸**——模型看到的"形状"和你标定的不一样，判断会漂。锁 2:1 就是为了防这个。

## 失效条件（何时需要重标）

| 变了什么 | 会怎样 | 要做什么 |
|---|---|---|
| 分辨率 / 画面比例（16:9 → 21:9 等） | 归一化后 ROI 框住的内容变了 | 重标 ROI |
| 游戏内 FOV / 视野设置 | 同样的框看到的地面范围变了 | 重标 ROI |
| HUD 缩放 / UI 缩放 | 框里混进 HUD 元素 | 重标 ROI |
| 换了分辨率但项目会先归一化到 1920×1080 | **框的位置仍然对**，但**画面内容比例**可能变 | 抽几帧 `aiprobe` 看判断是否还合理 |
| 只改 ROI 不改模型 | 模型训练时看的是旧视野 | 程序**仍能照跑**（输入尺寸没变），但判断会漂 → **用新视野的数据重训**才能保证效果 |

> [!important] 改 ROI = 换"视野"，要重训才保证效果
> `PassabilitySensor` 的预处理常量与 `ai-training/src/export_onnx.py` **一字不差对齐**。改 `input_size` 会直接和导出/训练端不一致（必须同步改三处）；只改 ROI（输入尺寸不变）虽然能跑，但模型看到的语义变了，**要用新视野的数据重训 + 重过金标门禁**（三档：≥0.85 可执行 / 0.60-0.85 仅观察 / <0.60 禁用）。

**怎么判断 ROI 歪了**：跑 `aiprobe`（实时探针）看模型判断，同时看画面里绿框框住的是什么——框里有天/手/UI，就歪了。

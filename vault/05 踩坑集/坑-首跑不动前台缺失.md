# 坑：autorun_walk 首跑角色一动不动——前台缺失 + 崩场无兜底

> [!bug] 症状
> 首跑：jsonl 0 行但回放图生成了（= 第一周期就崩，异常被顶层吞走）。修复后能跑但角色不动——按键全打进了控制台。

## 根因（两处叠加）

1. 命令**漏了 EnsureForeground**（airecord / patrol 都有，唯独没抄）——键鼠输入落不进游戏；
2. 游戏窗口最小化/不在前台时，截图函数（raiseAndWait:false 快速路径）直接抛异常，循环里没有兜底 → 一次异常整场退出。

## 修复

- 启动时抢前台（失败打警告"请点一下游戏窗口"）；
- 首帧带"置顶+等待"捕获，后续帧走快速路径；
- 逐周期截图兜底：失败/空帧 → 打日志、等 1 秒重试，绝不崩场；
- 原先静默的路径（UI 等待、定位未接受）全部打控制台。

> [!tip] 教训
> 输入注入类命令的清单第一项 = **焦点管理**；所有 IO 周期都要有"失败重试"而不是"崩场"。

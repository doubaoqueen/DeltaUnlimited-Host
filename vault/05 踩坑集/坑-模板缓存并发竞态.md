# 坑：测试随机崩溃 0xC0000005——清缓存释放了别人正在用的模板

> [!bug] 症状
> 全量测试随机中断：有时 177 过、有时 190 过、有时 158 过就停——Fatal error 0xC0000005（访问违例）炸在 Mat.get_Width()，测试宿主进程直接崩。

## 根因

`TemplateMatcher` 用**静态字典按路径缓存模板 Mat**；`FollowMarkerChainTests` 在测试收尾调 `ClearCache()` **逐个 Dispose** 缓存里的模板。xUnit **测试类默认并行**——另一个测试类（新增的倒计时回归测试）正拿着同一份缓存模板做匹配 → use-after-dispose。雷早就埋着，此前只有一个并行消费者没炸；**第二个消费者上线才引爆**。

## 修复

`ClearCache()` 从"逐个 Dispose + Clear"改成**原子换新字典**：旧字典整个交给 GC（Mat 终结器回收原生内存），调用语义不变（下次 LoadTemplate 重新读盘），竞态根除。三连跑全绿验证。

> [!tip] 教训
> **静态缓存 + 显式释放 = 并发地雷**。"退出时清理"用途的 API 不该出现在并行环境；要么引用计数，要么整体换血。

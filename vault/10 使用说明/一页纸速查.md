# 一页纸速查

> [!tip] 用法
> 忘了任何东西，先看这一页。想深入，点蓝色链接。

## 项目是什么

**DeltaUnlimited** = 一个"看得见的"桌面自动化助手：《三角洲行动》里**只靠截图 + 模拟键鼠**完成"进场 → 跑刀（搜刮/撤离）→ 结算"的流程。
**不读内存、不注入进程、不做任何战斗/击杀/瞄准辅助**；遇险即停交给人；数据不出机器。

## 三条红线（永远不越）

1. 不读内存 / 不注入 / 不改游戏文件；
2. 不做战斗辅助——检测到危险就停，交人；
3. 数据不出机器（AI 训练与推理全在本机）。

详见 [[决策-红线与边界]]。

## 架构三句话

- **感知**：截图 → OCR / 模板匹配 / 小地图定位 → 得到"画面是什么、我在哪"（[[架构-总览]]）；
- **决策**：链路引擎（界面流程 2Hz）+ 伺服循环（走位 8Hz）（[[决策-双引擎架构]]）；
- **执行**：拟人化键鼠（贝塞尔轨迹 + 落点校验 + 急停）（[[模块-输入拟人化]]）。

## 关键数字（改之前先看标定）

| 项 | 值 | 说明 |
|---|---|---|
| 设计分辨率 | 1920×1080 | 所有坐标/模板的基准 |
| 转向灵敏度 | `px_per_90deg = 4500` | 转 90° 需要的鼠标像素 |
| 可通行 ROI | `[592,656,648,324]` | AI 视觉看的那块画面 |
| 小地图面板 | 圆心 (165,185)，半径≈129 | 帧坐标（1920×1080） |
| 地图换算 | bj=128 / centerX=358155.6875 / centerY=750191.75 / z=4→16px | 世界坐标↔底图 |
| 点位 | 出生点 14 个 / 撤离点 4 个 | 常规2、丢包、条件 |
| 会话限额 | 240 分钟/日 | 可改，风险自担 |

## 三个最容易忘的坑

1. **小地图是圆的**（圆心 165,185），不是左上角矩形；
2. **开背包/地图/结算时没有小地图**，定位前要先判断界面状态（[[坑-背包界面不是小地图]]）；
3. **任何缩放过图像的坐标都必须还原**，否则系统性偏移（[[坑-坐标缩放偏移]]）。

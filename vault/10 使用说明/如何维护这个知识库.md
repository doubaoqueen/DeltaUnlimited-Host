# 如何维护这个知识库

> [!info] 一句话
> 这个库不是"写完就封盘"的文档，而是**活的记忆**。新东西随时加，旧东西及时改；规则只有三条：**带上出处、互相链接、说人话**。

## 1. 什么时候该加笔记

| 情况 | 加什么 | 放哪 |
|---|---|---|
| 做了一个**决定**（尤其是推翻旧决定） | `决策-XXX` | `04 决策记录/` |
| **踩了坑**并修好 | `坑-XXX` | `05 踩坑集/` |
| **标定了数值**（坐标/阈值/灵敏度） | `标定-XXX` | `06 标定台账/` |
| 搞懂了**一个概念** | `知识点-XXX` | `08 知识点/` |
| 加了**新模块/新工具** | `模块-XXX` / `工具-XXX` | `03 架构/` / `09 工具与数据/` |

**最省事的做法**：对 AI 说一句"把这个记进知识库"——它会按规范写好并更新相关索引。

## 2. 新建笔记的三步（手动时）

1. 在对应文件夹里新建笔记，文件名按 [[_写作规范]] 的命名规则；
2. 复制 `_模板/` 里对应的模板内容（决策模板 / 踩坑模板 / 标定模板 / 知识点模板）；
3. 填内容 → **至少链回 1~2 篇相关笔记**（在正文里写 `[[某笔记]]`），并在 `related` 属性里写上链接。

> [!tip] 模板怎么用
> 设置（左下角齿轮）→「核心插件」→ 打开「模板」→ 模板文件夹设为 `_模板`。
> 之后在笔记里按 `Ctrl+P` 输入"插入模板"，选对应模板即可；`{{date}}` 会自动变成当天日期。

## 3. 三条写作铁律

1. **带出处**：每篇末尾「## 出处」写清依据（文档路径/代码路径/Git 提交号）。没有出处的结论不可信。
2. **说人话**：读者是未来那个"什么都忘了的自己"。术语第一次出现要一句话解释（或者链到 `知识点-*`）。
3. **写"为什么"**：比"做了什么"更重要的是"当时为什么这么选、放弃了什么"。这是以后不重复踩坑的关键。

## 4. 链接习惯（决定了这个库好不好用）

- 提到某个模块/决策/坑时，**顺手加链接**：`见 [[模块-chain引擎]]`；
- 一个概念如果反复出现，就单独建一篇笔记，其他笔记都链过去（**不要复制粘贴**，复制会过期，链接不会）；
- 索引类笔记（[[01 项目总览]]、[[架构-总览]]、[[路线图与待办]]）要**定期补链接**，它们是入口。

## 5. 什么时候必须更新

- 改代码的同时（同一天）更新对应 `模块-*` 与 `标定-*`；
- 做了新决定 → 新开 `决策-*`，并在被推翻的旧决策笔记顶部加一段「> [!warning] 已变更 → 见 [[新决策]]」；
- 修了一个坑 → 把 `坑-*` 的 `status` 改成 `已解决`，补上"教训"；
- 待办完成 → 在 [[路线图与待办]] 里打勾 `- [x]`。

## 6. 不需要做的事

- ❌ 不需要写得像正式文档（这里是给你自己看的）；
- ❌ 不需要每篇都长（一句话 + 出处也是合格的笔记）；
- ❌ 不需要装插件（核心功能足够用；想尝试再装，但别为了插件而折腾）。

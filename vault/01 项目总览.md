# 01 项目总览

> [!info] 一句话
> DeltaUnlimited 是一个**"看得见的桌面自动化助手"**：只靠**截图 + 模拟键鼠**，替我在《三角洲行动·烽火地带》里跑那些重复的流程（进场 → 跑刀拾取 → 撤离 → 回大厅）。它**不读游戏内存、不注入进程、不做任何战斗辅助**。

## 1. 它到底在干什么

| 环节 | 它在做什么 | 人还要做什么 |
|---|---|---|
| **进场** | 从特勤处一路点到进入对局：模式选择 → 选零号大坝 → 配装 → 匹配 → 选干员 | 确认它没点错；异常时回车放行 |
| **跑刀** | `跑刀` = 不带装备（裸装）进图，只捡普通材料、尽量避开人，然后撤离——死了几乎不亏东西，是低成本攒钱的玩法 | 全程盯着，遇险按急停 |
| **撤离** | 跟着 HUD 导航标记（屏幕上指向标点的箭头/图标）走到撤离点，撤离、看结算、回大厅 | 同上 |

它和外挂的区别只有一句话：**它只能看见屏幕上有的东西，只能做真人用键鼠能做的动作**。所以它慢、会认错、必须有人在场——**这是设计，不是缺陷**。

## 2. 三条红线

> [!warning] 先记住这三条，再谈功能
> 功能可以少做，红线一条都不能碰。

| 红线 | 具体含义 | 越线会怎样 |
|---|---|---|
| **① 不读内存、不注入、不封包** | 只用屏幕截图当"眼睛"、用键鼠模拟当"手" | 读内存必须绕过反作弊，从此进入"军备竞赛"，项目性质从"自动化助手"变成"作弊器" |
| **② 不做战斗/击杀/瞄准辅助** | 对局内遇险一律停下交给人，连"自动逃跑"都不做 | 交火里跑路本身就是战斗行为；一旦沾战斗辅助，项目就没有边界了 |
| **③ 数据不出机器** | 模型全部本地跑；不接云端 API | 素材里有别人的昵称、队伍信息，上传即违反承诺 |

对局内还多一条更细的边界：**遇险即停给人**——检测到受击/危险就暂停链路让人接管，而不是自动反打或自动跑。

## 3. 现在做到哪了（2026-10-23 快照）

| 线 | 状态 | 一句话 |
|---|---|---|
| 进场链路 | ✅ 已通 | `enter_match.json` v7，2026-09-21 端到端真机验证；`data/screens.json` 现有 13 个大厅界面 + 4 个局内界面 |
| 跑刀 K1（撤离直通） | 🚧 进行中 | 伺服骨架 + `follow_marker`（跟随导航标记）已接进链路；K0 两局素材已入库；真机全程跑通还差"稳定知道自己在哪、往哪走" |
| 小地图定位 | 🚧 离线可用 | 用圆形小地图和官方底图做地形匹配来定位，P0 用户确认 6 对 0 错；C# 定位器、轨迹过滤、HUD 状态门已落地；实时化和分层地图待做 |
| AI 视觉 | 👀 observe-only | 可通行性传感器 v1 上线，但**只观察不决策**；金标集 0.695 落在观察档，enforce（强制干预）保持关闭 |
| 声音感知 | 📄 只立项 | 2026-10-22 决定**暂不投入**，只留方案 |
| GUI | ✅ G1/G2 | 一键开始/急停、暂停面板、系统托盘、实时日志窗 |

几个词先解释一下：

- **chain 引擎**：按 JSON 写好的步骤一步步跑"识别界面 → 点按钮 → 等下一个界面"的引擎，频率约 2Hz（每秒两次）。
- **伺服循环**：只管走位的高频小闭环（8Hz 左右）：看一眼 → 决定转多少 → 动作，一秒来回好几次。
- **observe-only**：模型只在旁边看和记录，不参与决策；关掉它，程序行为完全不变。
- **金标集**：一批人工确认过标准答案的图，用来给模型打分——分不够就不许上线。

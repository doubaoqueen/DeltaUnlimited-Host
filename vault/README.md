# DeltaUnlimited 知识库（Obsidian Vault）

> 一句话：**把"这个项目为什么这么做、踩过什么坑、标定值是多少"整理成 60+ 篇互相链接的笔记**，忘了就回来搜。

## 怎么打开

1. 安装 [Obsidian](https://obsidian.md)；
2. 启动 → 「打开文件夹作为库 / Open folder as vault」；
3. 选择本文件夹（`vault/`）；
4. 先读 **`00 开始这里.md`**。

> 不需要安装任何第三方插件。核心插件（模板/关系图/画布/属性）已预配置：
> 模板文件夹 = `_模板`，附件目录 = `assets`，关系图已按标签配色。

## 维护约定

- 每篇笔记带 YAML 属性（title/tags/status/created/related）与「## 出处」；
- 链接用 `[[笔记名]]`；不要在库外引用图片（图片放 `assets/`）；
- 与 `docs/` 的分工：`docs/` = 工程文档（可执行契约），`vault/` = 可读知识库（面向人）；
- 新增决策/坑/标定时两边同步更新（细则见 `10 使用说明/如何维护这个知识库.md`）。

## 说明

- 本库由 AI 基于项目文档、代码、Git 历史与讨论记录整理；**不确定处标 `❓待确认`**，如与代码冲突以代码为准；
- 笔记是纯文本 Markdown，可直接用任何编辑器打开、可被 Git 版本管理（已入库）。

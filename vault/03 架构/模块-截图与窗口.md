# 模块-截图与窗口

> [!info] 一句话
> 一切识别的起点是"把游戏客户区那一块像素抠下来"：按标题关键字找窗口 → 取客户区矩形 → 用 GDI `BitBlt` 拷到内存 → 得到一张 BGRA 图；点击时再把设计坐标按同一套比例换算回屏幕坐标。

## 1. 它负责什么、为什么需要它

三个必须解决的现实问题：

1. **窗口在哪**：游戏窗口可以随便拖、可以多开、控制台自己的标题里还带着命令行（容易自匹配），所以找窗口要按关键字 + 排除控制台宿主。
2. **截哪一块**：要的是**客户区**（不含标题栏/边框），不是整个窗口；窗口最小化时截回来是黑帧，必须先判 `IsIconic`。
3. **坐标怎么换算**：素材和坐标都按 1920×1080 写，实际窗口可能是 1600×900 或者被 DPI 缩放——截图与点击必须用**同一套**换算，否则"看得见点不着"。

## 2. 找窗口

`FindWindowByTitle(keyword)`（`CaptureService.cs:69-73`）：

```
枚举所有可见顶层窗口（标题非空）
  → 排除自己的控制台窗口（GetConsoleWindow）
  → 排除控制台宿主标题（含 cmd.exe / powershell / windowsterminal，忽略大小写）
  → 标题包含关键字（忽略大小写）→ 取第一个
```

关键字来自 `runtime.json → window_keyword`，默认 **"三角洲行动"**。找不到就抛异常并列出前 12 个可见窗口标题，方便判断是不是游戏没开或者标题变了（`windows` 命令可以直接列全部）。

## 3. 客户区、缩放与最小化

`GetClientScreenRect(hwnd)`（`CaptureService.cs:76-88`）返回客户区在**屏幕**上的 `(X, Y, W, H)`：

- 先 `IsIconic` 判最小化——**最小化时 `GetClientRect` 仍返回正常尺寸，但 `ClientToScreen` 给的是 (-32000,-32000)**，不判就会截回黑帧继续 OCR/乱点（评审 P1-3）；
- `GetClientRect` 拿宽高，`ClientToScreen(0,0)` 拿客户区左上角的屏幕坐标；
- 宽或高 ≤0 返回 null。

缩放比就是"客户区 / 设计分辨率"。真机诊断命令 `capture` 会打印这些，链路启动时也会打印一行（`LogWindowAnchor`）：

```
[坐标] 屏幕 2560x1440 DPI 120(125%)  窗口矩形 (0,0) 1600x900  客户区 (0,0) 1600x900 缩放 ×0.833/×0.833
```

（`LogWindowAnchor`，`CaptureService.cs:101-114`；下面是**格式示例**，数字随机器/DPI 不同）

## 4. 截图：桌面 DC + CAPTUREBLT + 负高度 DIB

实现要点（`CapturePixels`，`CaptureService.cs:279-343`）：

| 要点 | 为什么 |
|---|---|
| 源 DC 用**桌面 DC**（`GetDC(IntPtr.Zero)`）+ 客户区屏幕坐标 | 部分环境下用窗口 DC 拷贝会全黑 |
| `BitBlt(memDc, 0,0,w,h, hdcScreen, srcX,srcY, SRCCOPY + CAPTUREBLT)` | `CAPTUREBLT` 把分层窗口一起拷进来（否则可能漏掉某些覆盖层） |
| `CreateDIBSection` + `biHeight = -h` | 负高度 = 自上而下行序，直接对应 OpenCV Mat |
| DIB 像素 → `Mat(CV_8UC4)` 后立刻 `Clone()` | 必须在 `DeleteObject(hBitmap)` 之前深拷贝 |
| 返回 BGRA 4 通道 | 识别层会自己转 BGR（模板匹配）或灰度（OCR） |

两个公开入口：

- `CaptureWindowClient(keyword, pngPath)` → 落盘 PNG，返回 `CaptureOutcome`（含区域坐标与平均色，`LooksBlack` 判定平均亮度 <8 就是疑似黑屏）；
- `CaptureWindowMat(keyword|hwnd, raiseAndWait=true)` → 返回内存 Mat，不落盘，供帧差/识别。**`raiseAndWait=false` 时跳过"置顶 + 150ms"，连续采样用**（要求窗口已经在前台/最上层）。

`hwnd` 直定版是修过坑的：早期按关键字重新找窗，多窗口标题匹配时会"看 A 窗点 B 窗"（评审 P2-6）。现在链路把 `hwnd` 一路传下去。

## 5. 置顶与"截图钩子"

- `RaiseWindow(hwnd)` / `UnraiseWindow(hwnd)`：`SetWindowPos` 到 `HWND_TOPMOST` / `HWND_NOTOPMOST`，**不动键盘焦点**。截图前用，避免被别的窗口盖住截到别人的像素。
- `RegisterCaptureHooks(pre, post)`：截图前后各调一次的回调。悬浮状态面板（`overlay`）注册它，在 `BitBlt` 的那一瞬间把自己藏起来，否则面板会被截进帧污染识别（`CaptureService.cs:262-273, 309-315`）。

## 6. 什么时候必须 `EnsureForeground`

这是最容易搞混的一点，两者目的不同：

| 操作 | 需要什么 | 怎么做 |
|---|---|---|
| **截图** | 窗口在**最上层**（别被盖住） | `RaiseWindow` + 150ms（`raiseAndWait=true`） |
| **点击** | 部分游戏**非前台时忽略鼠标点击** | `ElementClicker` 里：`IsForeground` 为假才 `RaiseWindow` + 250ms + `EnsureForeground` + 200ms；已在前台就跳过（省 450ms） |
| **按键/长按** | 游戏必须持有**键盘焦点** | `EnsureForeground(hwnd)`：模拟左 Alt 骗到前台权限 → `SetForegroundWindow` → 150ms 后核对 |

具体在哪里调用（代码事实）：

- `key` / `pick_operator` 步骤、弹层自动关闭按键 → 按之前 `EnsureForeground`（`ChainCommand.cs:63, 335, 368, 484`）；
- `patrol` / `drill` / `airecord` / `aiprobe` 启动时调一次；
- `ElementClicker` 只在**非前台**时才置顶+抢焦点（`ElementClicker.cs:21-29`）。

> [!warning] "窗口化"是硬要求
> 独占全屏模式下 GDI 截不到画面（截回来通常全黑）。`capture` 命令发现疑似黑屏会直接提示"检查是否窗口化/游戏是否被独占全屏"（`Cli/README.md` 铁律②、`CaptureCommand.cs:19`）。

## 7. 坐标换算（截图与点击共用）

```csharp
// CaptureService.MapDesignToScreen，纯函数、有单测
double fx = client.W / (double)designW;
double fy = client.H / (double)designH;
return (round(client.X + designX * fx), round(client.Y + designY * fy));
```

- `designW/H` 来自 `runtime.json` 的 1920×1080；
- 元素坐标、`zones.json` 区域、`screens.json` 标记区域、AI ROI、小地图圆心全部按设计分辨率写；
- 点击路径：`ElementClicker` 用同一个 `GetClientScreenRect(hwnd)` 结果做换算（`ElementClicker.cs:34-39`），保证"截图看到的坐标"与"点击用的坐标"同源。

DPI 感知在 `EnsureDpiAwareness()` 里设置成 **Per-Monitor V2**（`SetProcessDpiAwarenessContext(-4)`），否则 125%/150% 缩放下截图与光标读回会错位；`InputService.Configure` 也会顺带调一次。

## 8. 常见症状对照表

| 症状 | 最可能的原因 | 先查什么 |
|---|---|---|
| 截回来全黑 | 独占全屏 / 窗口最小化 / 被遮挡 | 游戏是否窗口化；`capture` 输出的平均色与"疑似黑屏"提示 |
| 识别命中但点击偏 | 缩放比或窗口原点不一致 | `LogWindowAnchor` 打印的缩放比；`坑-坐标缩放偏移` |
| 点击被"安全网拦截" | 游戏抢光标 / 移动末点丢失 / 目标点算错 | `[Input] 光标落点校验` 日志里的实际坐标 |
| 按键没反应 | 游戏没有键盘焦点 | 日志里是否有"焦点切换失败"告警 |
| 截图里有状态面板 | 悬浮面板没注册截图钩子 | `overlay` 是否在跑、`RegisterCaptureHooks` 是否被调 |
